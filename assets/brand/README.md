# SunG1 Labs brand assets

`sung1-labs-logo.svg` is the primary horizontal logo.

The mark combines a rising sun, an orbital path, and an ascending `1` to represent practical engineering, systems thinking, and forward progress.

Recommended usage:

- Use the full wordmark on GitHub, npm, documentation, and website headers.
- Place it on a light background for the intended navy wordmark contrast.
- Use the left-hand mark alone when a square icon is required.
- Do not stretch, recolor, rotate, or place the logo over busy backgrounds.

Core colors:

- Navy: `#0B1220`
- Sun gold: `#FFB000`
- Orbit cyan: `#42D9FF`
- Slate: `#536174`
